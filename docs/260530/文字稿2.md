首先给没接触过生成函数的同学
介绍下这个非常好用的数学工具。
数列a的第i项乘以x的i次方，然后求和，
就构成了我们常说的普通生成函数。
这里a既可以是有穷数列，也可以是无穷数列。
比如香气四溢的数列11,45,14的生成函数
就是14x方+45x+11。
又比如屏幕展示了奇数数列的生成函数。
于是我们有了一个朴素的想法：
只需要证明这俩数列的OGF相等，
就能证明它们相等。
于是我们得到了目标：
证明屏幕下方的等式。

在证明等式之前，我们先来看一些OGF常用的数学工具。
首先是OGF乘法运算的性质，
直接套多项式乘法的定义就行。
接下来是本期视频会多次用到的几条泰勒展开式，
为了方便，后续我们都把这5条式子称为展开式1到5。
汉斯就不读这些式子了，
感兴趣的同学可以暂停视频看看。

有了上一页PPT介绍的数学工具，
我们就可以开始证明这条等式了。
首先问大家一个问题：
拿到这条等式，
你更倾向于从等式左边还是右边入手？
从左边入手需要化简，
从右边入手需要无中生有。
化简更容易，所以汉斯个人倾向于从左边入手。
首先，我们考虑交换求和顺序，让k在外层求和。
为此，我们考虑有哪些n对指定的k有贡献：
所有大于等于k的n，
对这条只含k的式子的贡献分别为C n k乘x的n次方。
于是我们得到了屏幕里的1式，
下面为了方便，设1式右侧的幂级数为A。
那接下来该怎么处理A式呢？
注意到A和展开式4的形式很接近！
我们对A提出一个x的k次方，
这样就能套用展开式4，
得到A的表达式了。

于是我们得到了屏幕上方的2式。
这里因为分子是k次方，分母是k+1次方，
所以我们提一个1减x分之1出来，
就能合并成1减x分之x的k次方了。
展开式1告诉我们，
ln（1+x）对应的数列恰好就是这里想要的k分之负1的k+1次方。
套用展开式1，我们就得到了屏幕中间的3式，
于是等式左边就成功化简为负1减x分之ln（1减x）。
真是一条简洁、优美的式子！
只需要把等式右边也化简为这条式子，这题就做完了。

有了之前的经验，我们模仿化简等式左边的过程，
考虑交换求和顺序，让k在外层求和。
所有大于等于k的n，对k分之1的贡献分别是x的n次方，
于是得到了屏幕上方的1式。
同样模仿化简等式左边的过程，
我们提出x的k次方，就可以套用展开式4了。
得到屏幕中间的2式。
由展开式1的推论，
数列k分之1的OGF就是负ln（1减x）。
对2式直接套用，这题就做完了。

接下来讲怎么用指数生成函数证明这条等式。
首先还是给没接触过EGF的同学
介绍下这个非常好用的数学工具。
我们看屏幕上方加粗的定义式，
它和OGF的定义式的唯一区别，
就是多除了一个n的阶乘。
但就是这点区别，导致它和OGF的性质和用法都不太一样。
另外，F上面的帽子只是一个装饰，
表明它是EGF，方便人的阅读。
为了帮助大家熟悉EGF，下面举些例子：
1，由展开式5，全1数列的EGF就是e的x次方。
2，把“1”的x换成qx，就得到了等比数列的EGF为e的qx次方。
3，令“2”的q=负1，就得到了1和负1交替的数列的EGF是e的负x次方。
为了方便，后续我们都把这3条式子称为EGF例1到EGF例3。
类似地，我们顺便得到了本题的目标，
就是证明屏幕下方的等式。

在证明之前，我们先来看一些EGF常用的数学工具。
首先是EGF的求导、积分性质。
不难发现，EGF求导和积分后，
恰好分别得到数列a向左、向右移动一位的EGF。
接下来和引入OGF时一样，我们考虑EGF的乘法运算。
设俩数列a、b的EGF分别为F、G，
套用多项式乘法的定义式，
然后借用一个n的阶乘，凑出C n i，
就得到了屏幕下方的式子。

这条式子表明，F乘G是这样一个卷积的新数列的EGF。
和OGF的乘法运算相比，它多了一个系数C n i。
这条性质有一个特别有用的推论，等会证明时会用到：
令b为全1数列，则G为e的x次方，
于是C n i乘a i的EGF就是e的x次方乘F。

有了上一页PPT介绍的数学工具，
我们就可以开始证明了。
和OGF一样，我们先化简等式左边。
注意到等式左边和上一页推论1的形式很像，
不妨设辅助数列a为k分之负1的k+1次方，
补充定义a0=0，
并设a的EGF为大A，
于是套用上一页PPT的推论1得，
等式左边的EGF为e的x次方乘大A。
当然，这里像OGF一样先交换求和顺序，
也能得到一样的结论，
只是稍微麻烦点，感兴趣的同学可以试试。
接下来我们来看怎么化简大A。
观察大A，我们来思考，
在哪会出现负1的n+1次方呢？
EGF例3！
也就是说，我们要想办法把e的负x次方变成大A！
首先把EGF例3中n=0的项去掉，
这样就只差系数n分之1了。
怎么构造出这个n分之1呢？
考虑到幂级数x的n减1次方的积分是x的n次方除以n，
这里刚好出现了n分之1，
所以我们需要进行一次积分。
回顾EGF的积分性质，积分会让数组右移1位。
所以为了抵消右移的影响，
我们需要先提1个x出来，让数组左移1位，再积分。
于是求出大A就是屏幕下方的式子。

所以我们只需要把等式右边也化简为这条式子就OK。
为此，我们需要想办法让右边也出现积分号。
这事儿确实比较难，这里我就直接讲做法了。
我们考虑用定积分表示H式。
受上一页PPT的启发，考虑幂级数的定积分，
从0到1积分，我们发现结果刚好是n分之1。
对幂级数求和，并交换积分号和求和号的顺序，
此时可以套等比数列求和公式，
得到屏幕中间的1式，这就是H的定积分表示。
把1式代入EGF的定义式，
并交换求和号与积分号的顺序，
接着套用EGF例1和例2，简单整理，
我们就得到了屏幕下方的定积分的式子。

现在等式左右两边都变成了定积分的形式，
我们离目标已经很近了！
观察左右两边的差异，
你觉得怎样换元可以让它们再靠近一点点呢？
诶，我们不妨猜测左边的e的负t次方
对应右边的e的（t减1）乘x次方。
所以尝试换元u=（1减t）乘x，
于是积分下、上限分别变为x、0，
最后像屏幕里这样简单整理等式右边，
我们就发现右边确实等于左边，
这题也就做完了。

最后总结一下OGF和EGF做法的异同。
首先是两种方法的共性。
1，都是先考虑化简更复杂的等式左边，
在取得阶段性成果后，才真正确认等式右边的化简目标。
2，对交换求和顺序的功力都有一定要求。
EGF方法中出现的积分可以看作求和的连续版本。
第一步就尝试交换求和顺序总是没错的。
3，和去年讲解的“期望的尾概率公式+容斥原理”方法相比，
化简目标都更为明确，不容易陷入迷茫、罚坐的境地。
接着是两种方法的差异。
1，为了处理C n k，
OGF方法要求熟悉展开式4，
EGF要求熟悉EGF的乘法运算的性质。
2，等式右边的推导：
化简等式右边的OGF比较简单，
模仿等式左边的化简过程就行。
但化简等式右边的EGF对注意力涣散的汉斯来说比较困难，
即使有前面的化简过程的启发，
也很难注意到H式竟然能用定积分表示！
